# SolarOS Git engine

This ESP-IDF component provides libgit2 1.9.7 for the SolarOS Git service.
See the [Git manual](../../doc/manual/git.md) for commands, authentication and
repository limits.

## Native integration

The public API is [solar_os_git_run](../../src/services/solar_os_git.h).
It takes an absolute VFS working directory, such as `/sdcard/project`, and
arguments beginning with the subcommand. Calls are synchronous, and only one
operation can run at a time. Run from a foreground worker with at least 28 KiB
of internal stack; output and cancellation callbacks run on that worker.
Display callers must flush output as it arrives. Dedicated Python and Lua Git
bindings are not provided.

The port uses SolarOS memory policy. Mutable library globals reside in PSRAM;
read-only data and initialization defaults reside in flash. Defaults are copied
once before the first library initialization or options call, preserving later
changes across init/shutdown cycles. The serialization guard and worker stack
remain internal. Git requires ordinary task context with caches enabled.

SSH uses the SolarOS SSH transport for upload-pack and receive-pack. Anonymous
HTTPS uses ESP-TLS and the system certificate bundle. Pack threads, subprocesses
and native mmap are disabled. Generated source adaptations provide Xtensa ABI,
stack-budget and VFS compatibility; preserve the component's compiler frame-size
check when updating dependencies.

FAT metadata replacement retains a backup and restores it after an ordinary
rename error. An existing backup blocks replacement until it is resolved.
Replacement is not atomic across power loss. Symlinks, submodule checkout and
external attribute filters are unsupported.

## Sources and licenses

The top-level [CMakeLists.txt](../../CMakeLists.txt) pins the libgit2 archive and
verifies its SHA-256. Downloaded sources remain unchanged in the build's
`_deps/libgit2` directory; local adaptations are generated by
[patch_sources.py](patch_sources.py) and [state_sources.py](state_sources.py).

libgit2 uses GPL v2 with a linking exception. Its bundled PCRE2, zlib, llhttp,
xdiff and SHA1 collision detection sources retain their own notices. Preserve
the upstream `COPYING`, `AUTHORS` and dependency license files in redistributions.

## Development checks

Run host interoperability tests from the repository root:

```sh
SOLAR_OS_LIBGIT2_SOURCE_DIR=/path/to/pinned/libgit2 python3 tests/test_git_client.py -v
```

The tests use the production service with host libgit2 and an isolated local
git-daemon. Test the ESP VFS, SSH and TLS adapters on hardware.

For an ESP32-S3 build, check RAM placement and initialization records using a
Python environment with `pyelftools`, such as the PlatformIO environment:

```sh
python components/solaros_git/check_memory.py .pio/build/t_deck_plus/firmware.elf
```
