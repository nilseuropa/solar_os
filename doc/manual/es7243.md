# ES7243 microphone ADCs

Select `es7243` or `es7243e` to match the fitted ADC. Both register an audio
input device and an exclusive `<name>.capture` PCM stream: signed 16-bit
little-endian samples, 16000 Hz, two channels. The `es7243` package group is
included in `full` on boards with I2C and expansion I2S support.

Supply the module's individual 7-bit I2C address and its I2S clock/data pins.
The ESP32 supplies MCLK, BCLK and LRCLK. For an ES7243 at address `0x13`:

```text
expansion attach es7243 mic0 i2c=i2c0 addr=0x13 i2s=1 mclk=4 bck=5 ws=6 din=7
audio devices
stream info mic0.capture
expansion detach mic0
```

Use a named I2C bus whose pins differ from the I2S signals. ADC initialization
starts its I2S clocks before configuring the codec. Closing the capture stream
releases its I2S channels. Detach is refused while the capture stream is open.
The supplied ADC address is also reserved while the expansion is attached.
Read timeouts are passed to the I2S receiver.

Input gain accepts 0 through 27 dB on ES7243 and 0 through 37.5 dB on ES7243E.
The ADCs quantize gain to their supported hardware settings. Gain readback reports
that selected value, and reopening capture preserves the original request.

## Shared ES8311 output

On ESP32-S3, `es8311-es7243` and `es8311-es7243e` combine ES8311 output with the
matching ADC on one I2S port. Select the `es8311` package group. One attachment
owns the shared clocks, both data pins, both I2C addresses and the audio backend.
Use this combined driver when the DAC and ADC share I2S wiring.

For an ES7243E at `0x14` and ES8311 at `0x18`, wired to these available GPIOs:

```text
expansion attach es8311-es7243e audio0 i2c=i2c0 addr=0x14 dac_addr=0x18 i2s=0 mclk=4 bck=5 ws=6 din=7 dout=8 pa=9
audio devices
expansion detach audio0
```

`addr` selects the ADC and `dac_addr` selects the ES8311. Optional
`pa=<gpio-or-controller:line>` is an active-high amplifier enable; for example,
`pa=gpiox0:12` uses an attached GPIO expander. It starts disabled, is enabled
after output initialization, and is disabled on shutdown. Both playback and
capture use standard stereo I2S with 16-bit samples at 16000 Hz. The existing
ES8311/ES7210 driver retains its TDM configuration.

## Quick reference

Attach `es7243` or `es7243e` with `i2c=<bus> addr=<7-bit address> i2s=<port>
mclk=<gpio> bck=<gpio> ws=<gpio> din=<gpio>`. Capture is PCM S16_LE, 16000 Hz,
stereo. For shared output, attach `es8311-es7243` or `es8311-es7243e` with the
same bindings plus `dac_addr=<7-bit address> dout=<gpio>` and optional
`pa=<gpio-or-controller:line>`. Close active streams before detaching.
