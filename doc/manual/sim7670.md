# SIM7670 modem

The `sim7670` expansion driver gives SolarOS exclusive access to a SIM7670
modem over a named UART. The Waveshare ESP32-S3-SIM7670G-4G V2.0 registers the
onboard module as `modem0` on `modem-uart` at 115200 baud.

List the registered module and inspect its SIM, LTE registration, and signal
status:

```text
modem list
modem status
```

Send a read-only or configuration AT command by quoting it as one shell
argument. The optional device name and timeout follow the command:

```text
modem at "AT+CGMM"
modem at "AT+COPS?" modem0 10000
```

The command accepts only text that starts with `AT` and rejects embedded CR or
LF characters. It prints the modem response, including an `ERROR`, before it
prints the SolarOS error name.

The modem also registers a GNSS receiver with the common service. Turn it on
before requesting a fix:

```text
gnss power on modem0
gnss fix modem0 5000
gnss power off modem0
```

`gnss fix` reports latitude, longitude, altitude, and UTC when the modem has a
valid fix. The SIM7670 AT/GNSS path does not provide satellite count or
accuracy fields, so those remain zero.

This driver does not yet provide PPP networking or CMUX. Wi-Fi remains the
SolarOS IP network interface on this board.

## Quick reference

`modem list` shows registered SIM7670 devices. `modem status [name]` reads SIM,
LTE registration, and signal status. `modem at <quoted-command> [name]
[timeout-ms]` sends an AT command. Use `gnss power on [name]`, `gnss fix [name]
[timeout-ms]`, and `gnss power off [name]` for the integrated GNSS receiver.
