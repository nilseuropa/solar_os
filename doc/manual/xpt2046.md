# XPT2046 resistive touch

`xpt2046` connects a four-wire resistive touch panel through its XPT2046 SPI
controller on ESP32 or ESP32-S3. The `full` flavor includes the driver; custom
flavors can enable the `xpt2046` group. The screen and SD slot remain separate
expansion devices.

## Attach

Attach the display first. Select a named SPI bus with MISO as well as MOSI and
SCK, and a chip select reserved for the touch controller:

```text
expansion attach xpt2046 touch0 spi=spi0 cs=gpio7 display=lcd0 irq=gpio15
input status
input test touch0
```

This example assumes the bus permits GPIO7 as another chip select and the board
allows GPIO15 as an input. Use the actual bus and free pins of your board.
`display=lcd0` routes touch to that display; it must exist and be ready when the
controller attaches. Use `display list` to find its registered target name.
The `io` attachment form and command completion offer
registered display targets whose names fit the 15-character expansion binding
limit. Multiple touch controllers can attach under distinct
names and chip selects.

The LCDWIKI MSP3520 exposes touch SCK on `T_CLK`, MOSI on `T_DIN`, MISO on
`T_DO`, chip select on `T_CS`, and the active-low pen signal on `T_IRQ`. These
are distinct from the LCD and SD pins. Connect the appropriate clock/data lines
to the same SPI bus if sharing it, and keep all chip selects separate. LCD SDO
can remain disconnected when display readback is unnecessary. Use 3.3 V logic.

The optional `irq` input lets the driver skip ADC transactions while the pen is
up. Without it, the driver polls pressure. The default SPI clock is 2 MHz;
`clock=1000` selects 1 MHz. Accepted clock values are 100..2000 kHz and apply
only to this controller, independently of the display and SD rates.

## Axes and calibration

`swap_xy=1` exchanges the raw axes. `invert_x=1` and `invert_y=1` reverse an
axis after the exchange. All three default to zero. Select these according to
how the touch layer is mounted relative to the display's default orientation.
The normal display/input transform handles subsequent terminal rotation and
scale changes.

A new source initially maps the 12-bit ADC range 0..4095 to the selected
display's base pixel dimensions. Actual resistive panels usually need measured
calibration. Inspect the raw coordinates with `input test touch0`, then save
the measured bounds through the existing input calibration command:

```text
input calibrate touch0 set 200 3900 250 3850 480 320
```

The six numbers are minimum X, maximum X, minimum Y, maximum Y, display width,
and display height. They are examples, not calibration values for every panel.
Use the reported coordinates after any swap/inversion settings. Calibration is
saved by source name and survives detach/restart; attachment preserves it.
`input calibrate touch0 reset` clears the saved calibration. Detach and reattach
to restore the default full-range mapping.

The contact threshold defaults to `pressure=400` and accepts values from 1 to
4095. Increase it to reject weak contacts or reduce it to accept lighter touches.

```text
expansion detach touch0
```

Detachment leaves the display and other devices on the bus available.
Automatic probing is not supported; attach the controller using its known wiring.

Python and Lua can use `solaros.expansion.attach("xpt2046", "touch0", CONFIG)`.
Set `spi` and `display` to names, `cs` and optional `irq` to GPIO numbers, and
optional `clock`, `pressure`, `swap_xy`, `invert_x`, and `invert_y` to integers.

## Quick reference

Attach with `expansion attach xpt2046 NAME spi=BUS cs=PIN display=DISPLAY`;
optional bindings are `irq`, `clock`, `pressure`, `swap_xy`, `invert_x`, and
`invert_y`. Use `input test NAME` for raw samples and `input calibrate NAME`
for saved bounds. Default clock: 2000 kHz; pressure threshold: 400.
`expansion detach NAME` releases the controller without removing its display.
